# Datasets

The datasets used in this project are not redistributed here.

Download the original datasets and place them in this folder with these names:

| File | Source |
|---|---|
| `classification_heart_failure.csv` | [Heart Failure Clinical Records - Kaggle](https://www.kaggle.com/datasets/rabieelkharoua/predict-survival-of-patients-with-heart-failure) |
| `regression_body_fat.csv` | [Body Fat Prediction Dataset - Kaggle](https://www.kaggle.com/datasets/fedesoriano/body-fat-prediction-dataset) |
| `clustering_obesity.csv` | [Obesity or CVD Risk Dataset - Kaggle](https://www.kaggle.com/datasets/aravindpcoder/obesity-or-cvd-risk-classifyregressorcluster) |

The public notebook expects those exact filenames.
